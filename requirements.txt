# Runtime deps for app.py ONLY, deliberately kept loose.
#
# Hard-pinning every package makes pip's resolver backtrack, and numpy==1.26.4 has no
# wheels for Python 3.13 (it would compile from source, which is what stalls a build).
# Ranges let the resolver pick wheels for whatever Python the host runs.
#
# scikit-learn stays pinned: artifacts/ensemble_deploy.joblib is a 1.6.1 pickle and the
# version that loads it must match the version that wrote it. 1.6.1 ships wheels for
# Python 3.9-3.13 but NOT 3.14, so the host MUST run 3.11 (see .python-version and the
# Deployment section of README.md). On 3.14 pip compiles it from source and the build dies.
streamlit>=1.34,<2
altair>=5.3,<5.5   # 5.5 deprecates alt.themes.register, which app.py uses
pandas>=2.0,<3
numpy>=1.26,<3
scikit-learn==1.6.1
xgboost>=2.0,<4
lightgbm>=4.0,<5
joblib>=1.3
